# 🔍 OpenCV Edge Detection

A simple real-time edge detection project built with Python and OpenCV.

This project uses the Canny Edge Detection algorithm to detect object edges from a live webcam feed.

## ✨ Features

- Real-time webcam capture
- Grayscale image conversion
- Canny edge detection
- Original and processed video windows
- Simple keyboard controls

## 🛠️ Requirements

- Python 3
- OpenCV
- Webcam

## 📦 Installation

```bash
pip install opencv-python
```

## 🚀 Usage

Run the program:

```bash
python3 main.py
```

Press `Q` to exit.

## 🧠 How It Works

1. Capture video from the webcam.
2. Convert each frame to grayscale.
3. Apply the Canny edge detection algorithm.
4. Display the original and processed frames.
